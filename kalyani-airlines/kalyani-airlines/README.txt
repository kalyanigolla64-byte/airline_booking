# Kalyani Airlines Website

A responsive airline booking website project.

## Run
1. Extract the ZIP.
2. Open the `kalyani-airlines` folder in VS Code.
3. Double-click `index.html`, or use VS Code Live Server.
4. Internet is needed for the Unsplash city/air travel photos and Google Fonts.

## Pages
Home, Destinations, Book Flight, About Owner, Contact, Login.

## Important
This is a student/demo website. Booking, login and contact forms are front-end demonstrations only; no real payment, account, or reservation system is connected.
